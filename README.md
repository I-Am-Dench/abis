# ABIS (**A**uto-generated **BI**nary **S**erializer)

ABIS is a small serialization library that aids in the serialization and deserialization of complex data structures to and from byte buffers. This library is intended to be used in conjuction with the [ABIS tool](./cmd/abis/) which auto-generates serialization and deserialization functions for exported types.

ABIS currently only supports big-endian serialization. All custom serialization and/or deserialization methods should call the corresponding [ABIS functions](abis.go).

Module Installation:

```bash
go get github.com/I-Am-Dench/abis@latest
```

## ABIS Tool

Tool Installation:

```bash
go install github.com/I-Am-Dench/abis/cmd/abis@latest
```

The ABIS tool should be used with the [Go generate](https://go.dev/blog/generate) command.

### Example

To start generating the serialization methods, start by defining a file with your target struct.

#### `example.go`

```go
//go:generate abis example.go
package example

type Account struct {
    Name    string
    Age     uint
    IsAdmin bool
    Score   float64
}
```

Note the `go:generate` directive which will run the ABIS tool with the name of our struct file as the argument. The tool will only generate methods for structs defined in the target files. Running `go generate .` will cause ABIS to generate the following file:

#### `example_abis.go`

```go
// auto-generated by abis; created on 2026-09-20T16:52:58-04:00
package example

import (
	"math"
	"github.com/I-Am-Dench/abis"
)

func (a Account) AppendBinary(buf []byte) ([]byte, error) {
	buf = abis.AppendString(buf, a.Name)
	buf = abis.AppendUint64(buf, uint64(a.Age))
	buf = abis.AppendBool(buf, a.IsAdmin)
	buf = abis.AppendUint64(buf, math.Float64bits(a.Score))
	return buf, nil
}

func (a *Account) AdvanceBinary(data []byte) ([]byte, error) {
	var err error
	if data, err = abis.AdvanceString(data, &a.Name); err != nil {
		return data, abis.NewAdvanceError("Name", nil)
	}
	if data, err = abis.AdvanceUint(data, &a.Age); err != nil {
		return data, abis.NewAdvanceError("Age", nil)
	}
	if data, err = abis.AdvanceBool(data, &a.IsAdmin); err != nil {
		return data, abis.NewAdvanceError("IsAdmin", nil)
	}
	if data, err = abis.AdvanceFloat64(data, &a.Score); err != nil {
		return data, abis.NewAdvanceError("Score", nil)
	}
	return data, nil
}
```

Types which already implement `encoding.BinaryAppender` or `abis.BinaryAdvancer` will not have their corresponding methods generated. Non-basic types, such as structs, will not use the `abis` serialization functions, and will instead use the `encoding.BinaryAppender` and `abis.BinaryAdvancer` methods.

Currenly, only serialization and deserialization of arrays of `encoding.BinaryAppender`'s and `abis.BinaryAdvancer`'s are supported.
